# Mobileo India Website

A responsive premium phone storefront inspired by elegant e-commerce layouts, designed for Indian smartphone shoppers.

## Features
- Luxury modern homepage inspired by premium brand sites
- Top selling phone brands in India sections
- Product cards for best-selling phones
- Filter buttons for categories such as 5G, budget, and premium
- Cart counter interaction
- Welcome offer modal instead of cookie banners
- Newsletter signup section
- Fully responsive layout for mobile, tablet, and desktop

## Run locally
Open `index.html` directly in a browser, or serve it with a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project structure
- `index.html` – main storefront layout
- `styles.css` – complete styling and responsiveness
- `script.js` – product filtering, cart logic, modal, and basic interaction

## Notes
This is a front-end storefront concept using static HTML/CSS/JS. It is ready to be connected to a backend or headless e-commerce platform later.
